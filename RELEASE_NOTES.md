## T1TSMetric 1.3.0

Windows x64 portable build. Extract the full ZIP and run **T1TSMetric.exe**. No installer, Node.js or VRoid Studio is needed to use the release.

### Changes

- Visible credit to **github.com/nineflowersoflotus**.
- Fixed Recycle Bin opening, with Windows ShellExecute and an Explorer fallback.
- Clicking the avatar excites secondary springs; the body and spring motion recover at different rates.
- Lower per-frame physics overhead and fewer unnecessary UI updates.
- Source project includes tests and repeatable release scripts.

English is the default; Portuguese is available in Options. Volume variation remains 2× by default. The 60 FPS option is a target dependent on GPU/driver performance. The executable is unsigned.

File removal always requires confirmation. Files in the Recycle Bin continue occupying space until emptied through Windows. No registry cleaning, permanent deletion or telemetry is performed.
